相談内容および「食のバズ歴史」の戦略レベル（GEM3）を確認しました。 かなりハイレベルな戦略を組まれているため、単なる「データ収集ツール」で終わらせず、GEM3の意思決定を支援する「参謀（インテリジェンス）ツール」として設計する必要があります。

以下に、システム構成案と、シビアな視点での意見を提示します。

1. Youtubeリサーチアプリ構築案
目的
GEM3（タイトル＆サムネ案）の「STEP 1: 市場・キーワード分析」に対し、推定ではなく実数を供給する。

機能要件
すでに実装済みのコメント取得に加え、以下2つを実装します。

A. ランキング・急上昇監視 (Market Watch)

機能: カテゴリ「科学と技術」「教育」「エンタメ」等の急上昇（Most Popular）を毎日自動取得。
狙い: YouTube全体のトレンド波形を掴む。

B. 競合・トレンド徹底リサーチ (Deep Research)

機能: 特定キーワード（例：「明治 牛鍋」）での検索結果上位50〜100件を取得し、以下の指標を算出・ソートする。
ジャイアントキリング指数 (Giant Killing Score): 動画再生数 ÷ チャンネル登録者数
これが 3.0〜5.0以上 の動画は、「チャンネルの固定ファンではなく、企画とサムネの力でバズった」ことを意味します。これが最も真似すべき「手本」です。
鮮度 (Freshness): 直近3ヶ月〜1年以内の動画か？
3年前のバズは「先行者利益」であり、現在再現できるとは限らないため除外判定に使います。
タグ・共起語抽出: 上位動画が共通して使っているタグやタイトル文言を抽出。


技術スタック案

言語: Python
API: YouTube Data API v3
使用ライブラリ: google-api-python-client, pandas (分析用), isodate (再生時間計算用)
構成:
research_rankings.py: ランキング取得
analyze_keyword.py: キーワード検索＆ジャイアントキリング分析
export_to_gem3.py: GEM3プロンプトに入力可能な形式（Markdown表）で出力


2. シビアな視点での意見 (Consultation)

GEM3プロンプトを拝見した上での、率直かつシビアな意見です。

① 「データ」に使われるな、「データ」を使い倒せ

GEM3は非常に優秀な「軍師」ですが、入力されるデータが「なんとなくの感覚」だと、出力も「もっともらしい空論」になります。 このツールは、GEM3の「STEP 1-1 キーワード・ポートフォリオ」における**「Volume (検索ボリューム)」と「Competition (競合性)」を、主観から客観的な数値に変えるため**にのみ存在すべきです。 「ツールがこう言っているからこの企画にする」という思考停止に陥ると、チャンネルの「色（ブランド）」が死にます。最終決定権はあくまで「監督（あなた）」が持ってください。

② SEOよりも「関連動画（ブラウジング）」を狙え

歴史ジャンルにおいて、検索（SEO）からの流入は重要ですが、爆発的なバズ（10万再生越え）を作るのは**「関連動画（Recommended）」です。 SEOツールとして「検索ボリューム」を追うだけでなく、「今伸びている競合動画の『関連動画』にどうねじ込むか？」という視点が必要です。 そのためには、ツールで「競合のタイトル・概要欄・タグの完コピ（ベンチマーク）」を行い、そこに「サムネの差別化（GEM2）」**で勝つ、というコバンザメ戦術が初期〜中期には有効です。これを自動化しましょう。

③ 「ジャイアントキリング」のみを信じろ

ランキング上位の大御所（登録者数100万人超）の動画データはノイズです。彼らは「今日、水を飲んだ」という動画でも10万再生いきます。 リサーチアプリでは、**「登録者数が自分と同等〜10倍以内（例えば1万人以下）なのに、10万再生出している動画」**だけを抽出するフィルタリング機能を強力に実装すべきです。それ以外は見る必要すらありません。

1. 「1万登録・1万再生」に対するシビアな意見
その指標は**「正解」ですが、以下の「落とし穴」**を回避するロジックを追加すべきです。

まぐれ当たり（One-hit wonder）の除外:
「たまたま検索トレンドに乗っただけ（時事ネタ）」の可能性があります。
👉 対策: その動画の投稿時期が「直近（1年以内）」かつ、同チャンネルの他の動画も「悲惨すぎない（アベレージもチェック）」かどうか見る視点が必要です（ツール上の実装は必須ではないが、解釈時に注意）。
広告ブーストの検知:
Google広告で再生数を買っている動画は、再生数は多いが「高評価・コメント」が極端に少ないです。
👉 対策: **「エンゲージメント率（(高評価+コメント)/再生数）」**も同時に算出し、これが異常に低い（例: 1%未満）動画はノイズとして除外します。
